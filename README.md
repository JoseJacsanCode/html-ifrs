# HTML IFRS

Repositório criado para acompanhar meus estudos de **HTML5**, reunindo exemplos e exercícios práticos desenvolvidos durante o aprendizado.

## 📚 Sobre o projeto

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web. O foco inicial é compreender a estrutura de documentos HTML, seus principais elementos e a utilização de tags semânticas e estruturais.

## 📂 Estrutura do projeto

```text
html-ifrs/
└── meu-projeto-html/
    ├── index.html
    └── tags-estruturais.html
```

### `index.html`

Página inicial simples utilizada para praticar a estrutura básica de um documento HTML, incluindo:

* `DOCTYPE`
* `html`
* `head`
* `meta`
* `title`
* `body`
* `h1`
* `p`

### `tags-estruturais.html`

Arquivo destinado aos estudos e exemplos relacionados às **tags estruturais do HTML5**.

## 🎯 Objetivos

* Aprender a estrutura básica do HTML5;
* Conhecer as principais tags HTML;
* Praticar HTML semântico;
* Desenvolver páginas web simples;
* Criar uma base para estudos posteriores de CSS e JavaScript.

## 🛠️ Tecnologias

* **HTML5**

## 🚀 Como executar

Não é necessário instalar nenhuma dependência.

1. Clone o repositório:

```bash
git clone https://github.com/JoseJacsanCode/html-ifrs.git
```

2. Entre na pasta:

```bash
cd html-ifrs
```

3. Abra o arquivo `index.html` em qualquer navegador.
